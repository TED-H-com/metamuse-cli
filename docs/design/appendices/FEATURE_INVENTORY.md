# MetaMuse CLI — 功能明細補充

這份明細保留先前已討論的功能，不取代本版FR／architecture。舊ID用於來源追溯；正式需求以02_SPEC.md的FR為準。

## 原始功能目錄（補充）

P0 = 首個可交付版本；P1 = 完成首條實際流程後；P2 = 有需求才做。P0 功能可以限制單平台與小範圍，不能以擴平台取代真正完成。

| ID | 能力 | 等級 | 交付內容與邊界 |
|---|---|---|---|
| I01 | 連結／檔案統一入口 | P0 | 單筆／清單 URL、JSON/CSV/文字匯入；保留真正來源 |
| I02 | 貼文讀取 | P0 | 指定來源的正文、URL、來源 ID、時間；缺失欄位保持未知 |
| I03 | 留言／回覆樹 | P0 | 小範圍讀取、parent ID、去重、完整性標記；不是全網歷史抓取 |
| I04 | 範圍與能力預檢 | P0 | 平台×帳號×操作×backend；unsupported 與未測分開 |
| I05 | 增量收集 | P1 | checkpoint、新增／編輯觀測；看不到不直接當刪除 |
| I06 | 來源變更比較 | P1 | 保留前後版本與當時可見範圍；頁面不同不自動推論作者意圖 |
| M01 | 影音 metadata 與下載 | P0 | 先取 metadata，確有需要才下載；支援狀態依 extractor 實測 |
| M02 | 原字幕／自動字幕 | P0 | 有提供才取得；保存語言、來源類型、時間軸及缺失資訊 |
| M03 | ASR 逐字稿 | P1 | 無字幕時可選處理；provider 自選，雲端分享需允許；不假稱人工校對 |
| M04 | 影音基礎處理 | P1 | 音訊擷取、格式轉換、明確起訖裁切、字幕格式轉換 |
| M05 | 圖片基礎處理 | P1 | 尺寸、壓縮、使用者指定裁切、alt text 草稿；不內建審美或爆款配色 |
| M06 | 畫面文字理解 | P2 | 字幕／可用文字不足且任務確有需要時才分析畫面；保存時間與不確定性 |
| D01 | 素材關聯 | P0 | 貼文↔影片↔字幕↔留言↔報告，共用 source／asset 關係 |
| D02 | 可追溯引用 | P0 | 原文片段／留言 ID／時間碼，可回到證據；非 Muse 口頭保證 |
| D03 | 搜尋與片段擷取 | P0 | 文本查詢、欄位過濾、分頁，回傳原文與 provenance |
| D04 | 對外分享資料包 | P0 | 最小必要摘錄、隱私處理、內容清單、來源方式、分享核准範圍 |
| D05 | 範圍與完整性報告 | P0 | 未讀、零結果、部分、達上限、驗證失敗各自表示 |
| D06 | 同內容跨平台關聯 | P1 | 保留不同 publication ID；不得只依相似文字武斷合併 |
| A01 | Muse 主題對話 | P0 | 本地 discussion↔Muse session 映射，持續問答，不改 harness |
| A02 | Muse 發送／讀取狀態 | P0 | 問答關聯、讀取 cursor、逾時先查歷史、不盲目重送 |
| A03 | 對話證據保存 | P0 | 送出問題與資料包版本、原始回答、主 Agent 結論分開 |
| A04 | 有界追問 | P0 | 主 Agent 決定是否繼續；輪數／時間／輸出量上限可設定 |
| A05 | Provider 替換介面 | P1 | 其他協作 Agent 可另接入；不同 provider 的能力不假設相同 |
| W01 | 中性草稿保存 | P0 | 主 Agent 產稿，工具存稿；不暗藏第二個策略 LLM |
| W02 | Canonical 與平台版本 | P0 | 按使用者選擇同步或分開；保留哪些欄位／附件被調整 |
| W03 | 客觀格式檢查 | P0 | 長度、換行、URL、附件、格式、使用者禁用符號與必填資料 |
| W04 | 事實／素材檢查 | P0 | 來源缺口、日期時區、名稱／連結衝突；語義判断需標記且由 Agent 審核 |
| W05 | 草稿預覽／匯出 | P0 | 可複製純文字、Markdown、素材包；預覽不假裝平台實際 rendering |
| W06 | 使用者偏好 | P0 | 顯式設定或本次指示；單篇修訂不自動永久化 |
| O01 | 發布準備與批准 | P1 | 綁定完整內容版本、附件、平台、帳號、目的地及時間 |
| O02 | 單次發布／對帳 | P1 | 一個已驗收目標先行；結果不明先查，不重點送出 |
| O03 | 留言工作清單 | P1 | 新增／待回覆／草稿／已核准／已回覆，保留正確父層與帳號 |
| O04 | 指定時間排程 | P2 | 只有使用者設定的時區與日期；不推薦黃金時段；重驗批准與資料版本 |
| O05 | 跨平台部分成功 | P1 | 各目標獨立記錄，不聲稱整批原子成功，不自動刪成功貼文做回滾 |
| R01 | 成效匯入與快照 | P1 | 原值、單位、來源、擷取時間、平台、貼文／帳號 scope、缺值 |
| R02 | 中性成效比較 | P1 | 同定義與相近觀測時間；derived rate 標公式，不自動升級寫作規則 |
| R03 | 使用者指定觀測任務 | P2 | 有明確範圍才排程；與代理商大量監控或全網爬取分開 |
| U01 | 失敗保留與續跑 | P0 | 每個項目自己的進度；程序中斷後不丟失 queue |
| U02 | 執行成本與資源界線 | P0 | 最大項目／位元組／時長／AI 輪數；未知供應商配額不得虛報 |
| U03 | 能力與環境診斷 | P0 | 憑證可用性、backend 版本、實測項目、錯誤分類；不輸出 secret |
| U04 | 保存期限／刪除 | P0 | 私有資料與衍生物 retention；遠端 Muse 刪除範圍未確認時明示限制 |
| U05 | 輕量 UI | P2 | 只是既有資料與工具的視圖，沒有另一套寫作契約或 AI runtime |
